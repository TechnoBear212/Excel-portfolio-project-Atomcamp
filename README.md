# 📊 Sales Data Analysis & Dashboard Project

## 📌 Overview
This project is part of my portfolio work from Atomcamp, where I performed end-to-end data analysis on a sales dataset. The goal was to extract meaningful business insights, evaluate performance, and provide actionable recommendations using data visualization and analysis techniques.

---

## 🎯 Objectives
- Analyze sales performance across different dimensions
- Identify trends, patterns, and anomalies in the data
- Evaluate profitability and revenue drivers
- Build interactive dashboards for better decision-making
- Provide data-driven business recommendations

---

## 📂 Dataset Description
The dataset includes transactional sales data with key attributes such as:
- Order details
- Sales revenue
- Profit and cost
- Product categories
- Customer segments
- Time-based features (date, month, year)

---

## 🛠️ Tools & Technologies Used
- **Excel / SQL** – Data cleaning and preprocessing  
- **Power BI** – Data visualization and dashboard creation  
- **Python (optional if used)** – Data analysis and transformation  

---

## 🔍 Key Analysis Performed
- Sales trend analysis over time
- Profitability analysis by product/category
- Customer segmentation insights
- Regional or category performance comparisons
- KPI calculations (Total Sales, Profit, Profit Margin)

---

## 📊 Dashboard Features
- Interactive filters (date, category, region)
- KPI cards for quick insights
- Visualizations including:
  - Bar charts
  - Line graphs
  - Pie charts
- Profitability breakdowns
- Trend analysis visuals

---

## 💡 Key Insights
- Identified high-performing and underperforming product categories
- Highlighted periods of peak and low sales
- Discovered areas with low profit margins despite high sales
- Recognized customer segments contributing most to revenue

---

## 🚀 Recommendations
- Focus marketing efforts on high-margin products
- Optimize pricing strategies for low-profit items
- Improve inventory planning based on demand trends
- Target high-value customer segments
- Reduce operational inefficiencies in low-performing regions

---
## 📈 Future Improvements
- Integrate real-time data sources

- Enhance dashboard interactivity
- Deploy as a web-based analytics tool
